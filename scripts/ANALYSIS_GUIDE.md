## 二、深度分析规则（步骤4）

### 2.1 每场至少3次精准WebSearch（禁止泛搜）
1. `"{主队} vs {客队} prediction preview lineup {日期}"`
2. `"{主队} injuries team news {月份} {年份}"`
3. `"{主队} {客队} head to head stats recent form"`

### 2.2 球队排名标注规则（必做）

每支球队在报告中显示时，必须在其名称右下角以小字标注联赛排名：
- 格式：`球队名<sub class="rank-tag">排名第N</sub>` 或 `球队名<sub class="rank-tag">[N]</sub>`
- CSS样式：`.rank-tag { font-size: 0.55em; color: var(--text-muted); vertical-align: sub; margin-left: 2px; }`
- 排名来源：搜索 `"{联赛} standings table {年份}"` 获取最新积分榜
- 资格赛无排名时标注赛制阶段：如 `<sub class="rank-tag">第3轮资格赛</sub>`

**HTML示例：**
```html
<div class="match-teams">
  <span class="home">埃因霍温<sub class="rank-tag">[1]</sub></span>
  <span class="vs">VS</span>
  <span class="away">格罗宁根<sub class="rank-tag">[12]</sub></span>
</div>
```

**应用范围**：所有出现球队名称的位置（比赛总览表、逐场分析卡片、比分预测汇总表、市场信心指数图表数据标签）。

### 2.3 泊松分布比分预测模型 V2（含动态系数调整）

本模型在V1基础上新增：指数衰减加权、xG数据融合、市场隐含λ混合、动态系数自校准。

#### 第一步：指数衰减加权基础λ值（V2改进）

不再使用简单平均，改为**近期比赛权重更高**的指数衰减加权：
- 权重 w_i = 0.85^i（i=0为最近一场，i=9为第10场）
- 加权场均进球 = Σ(进球_i × w_i) / Σw_i
- 加权场均失球 = Σ(失球_i × w_i) / Σw_i

**基础λ计算（动态主客场系数，非固定值）：**
- 主队基础λ = (主队加权场均进球×0.75 + 客队加权场均失球×0.25) × 动态主场加成
- 客队基础λ = (客队加权场均进球×0.75 + 主队加权场均失球×0.25) × 动态客场折扣
- 无进球数据时用赔率反推：主队λ≈1/胜赔×2.5，客队λ≈1/负赔×2.5

**动态主客场系数（V2新增，替代固定1.15/0.90）：**
- 读取近30天该联赛所有比赛，计算主场胜率
- 主场加成 = 0.95 + (主场胜率 × 0.40)，范围约1.05-1.35
- 客场折扣 = 1.20 - (主场胜率 × 0.40)，范围约0.80-1.05
- 无法计算时回退默认值：主场1.15，客场0.90

#### 第二步：xG数据融合（V2新增）

当搜索到xG数据时，用xG替代实际进球计算更稳定的λ值：
- 若有xG数据：xG加权λ = (xG_for加权均值×0.75 + 对手xG_against加权均值×0.25) × 主客场系数
- 最终基础λ = 0.6 × 进球λ + 0.4 × xGλ（无xG时纯用进球λ）
- 标注："已融合xG数据，权重40%"

#### 第三步：H2H历史进球加权调整（保持V1逻辑，权重动态化）

- 搜索近6-10次H2H具体比分，计算H2H场均总进球
- H2H调整因子 = H2H场均总进球 ÷ 基础模型预期总进球
- 分级规则：
  - H2H场均≥4.0球：因子取max(因子,1.5)
  - H2H场均3.0-3.9：因子取max(因子,1.3)
  - H2H场均2.5-2.9：因子取max(因子,1.15)
  - H2H场均2.0-2.4：因子取max(因子,1.0)
  - H2H场均<2.0：因子取min(因子,0.9)
  - H2H数据不足3场：跳过调整

#### 第四步：市场隐含λ混合（V2新增，融合赔率信息）

从赔率反推市场对进球数的预期，与模型λ做加权混合：
- 市场隐含主队λ = 1/胜赔 × 2.5（归一化后）
- 市场隐含客队λ = 1/负赔 × 2.5
- 混合公式：最终λ = 0.65 × 模型λ + 0.35 × 市场隐含λ
- 市场隐含λ作为"聪明钱"信号，修正模型偏差

#### 第五步：动态系数自校准（V2核心改进，基于历史预测命中率追踪）

**校准原理**：每天报告的"历史预测命中率追踪"部分会统计最近7天的预测准确率。根据偏差方向自动调整系数。

**校准流程（每次分析时执行）：**
1. 读取最近3-7天的报告，提取预测总进球 vs 实际总进球
2. 计算系统偏差比 = 平均(预测总进球 / 实际总进球)
   - 偏差比 > 1.10：模型系统性高估 → λ乘以0.92
   - 偏差比 < 0.90：模型系统性低估 → λ乘以1.08
   - 偏差比在0.90-1.10：无需校准
3. 计算方向命中率（胜平负方向预测准确率）
   - 方向命中率 < 45%：信心评级额外减1星
   - 方向命中率 > 60%：信心评级额外加1星
4. 计算比分命中率
   - 比分命中率 < 10%：标注"近期比分预测偏低，建议关注方向而非精确比分"
5. 按联赛分组校准（不同联赛偏差不同）：
   - 如英超预测偏高但西甲准确 → 仅调整英超的系数

**报告中标注校准信息：**
```
📊 动态校准：
- 近7场预测总进球均值: 3.2 | 实际均值: 2.8 → 系统高估14% → λ×0.92已应用
- 方向命中率: 52% (近7场命中4/7) → 信心评级不变
- 比分命中率: 14% (近7场命中1/7)
```

#### 第六步：泊松计算与输出
- P(k;λ)=e^(-λ)×λ^k/k!，遍历k1=0..6,k2=0..6
- 取概率最高的2-3个比分，标注概率百分比
- 标注完整调整链路信息：
  ```
  基础λ(指数加权) → xG融合(40%) → H2H调整(1.5x) → 市场混合(35%) → 动态校准(×0.92) → 最终λ=2.8
  ```

### 2.4 冷门信号检测
发现异常时调低信心1-2星并标注⚠️：
- 凯利指数>1.0
- 赔率与实力/xG严重不符
- 赛程疲劳（3天内有欧战/连续客场/3天2赛）
- 比赛动机差异（保级vs无欲、杯赛轮换）
- 转会窗影响（核心离队/新援磨合）

### 2.5 分析维度全覆盖
每场比赛必须分析：盘口赔率（胜平负/让球/亚盘/凯利）、H2H近6次比分、双方近5场战绩、积分排名（含排名标注）、主客场胜率、伤停名单、赛前新闻、xG趋势、赛程疲劳、比赛动机、转会影响、教练因素。信心评级1-5星（★★★☆☆格式），冷门信号自动调低，动态校准方向命中率额外加减星。

### 2.6 联赛 vs 资格赛特殊要求
- **联赛**：积分排名、与欧战/降级线距离、联赛积分榜（前5-8名高亮）、比赛结果联赛影响（胜平负三种结果对排名影响）
- **资格赛**：额外搜索当轮对阵总览、首回合详细结果（进球球员时间助攻红黄牌VAR点球）、首回合比赛统计（控球射门射正xG角球犯规）、晋级路径、比赛结果晋级影响

### 比赛回顾格式（所有比赛统一）
必须包含5项：比赛基本信息行（日期+场地+比分+半场比分+裁判）、进球球员表格（时间/球员/球队/助攻或方式）、关键事件列表（红黄牌/点球/VAR/进球被吹）、完整比赛统计表格（控球率/射门/射正/xG/角球/犯规/传球成功率）、战术分析段落。
