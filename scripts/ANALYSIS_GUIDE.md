> 本文件是 AI 深度分析和报告生成的规则参考。读取 `matches_data.json` 获取比赛列表后，按本文件规则进行分析和报告生成。

## 一、最高优先级规则

- **只生成当天日期的报告**，未来日期一律忽略
- 报告路径：`/workspace/jinbet/predictions/{TODAY}/index.html`
- 所有操作在 **gh-pages 分支**上，禁止切换到 master
- 如存在 `report_template.md` 则先读取并遵循
- 严格参考 `/workspace/jinbet/predictions/2026-07-21/index.html` 的风格和结构
- 当天无比赛则生成"足球新闻汇总"风格报告（参考 `/workspace/jinbet/predictions/2026-07-28/index.html`）
- **H2H 必须双向代入 λ**：每场比赛的 H2H 既要算「总进球因子」（对称，改变总量），也要算「方向性再分配」（非对称，总量守恒）。
  仅调总进球而忽略胜负记录属于**不合格输出**。详见 2.3 第三步 B 部分。
- **λ 链路必须 7 段完整**：`基础λ → xG融合 → H2H调整 → 市场混合 → 动态校准 → 零封修正 → 最终λ`。
  缺任何一段（尤其是 H2H 段缺少方向再分配数值）必须回退重算，禁止输出残缺链路。

### 2.3 泊松分布比分预测模型 V2.2（含动态系数调整 + H2H方向性再分配）

本模型在V1基础上新增：指数衰减加权、xG数据融合、市场隐含λ混合、动态系数自校准。

#### 第一步：指数衰减加权基础λ值（V2改进）

不再使用简单平均，改为**近期比赛权重更高**的指数衰减加权：
- 权重 w_i = 0.85^i（i=0为最近一场，i=9为第10场）
- 加权场均进球 = Σ(进球_i × w_i) / Σw_i
- 加权场均失球 = Σ(失球_i × w_i) / Σw_i

**基础λ计算（动态主客场系数，非固定值）：**
- 主队基础λ = (主队加权场均进球×0.75 + 客队加权场均失球×0.25) × 动态主场加成
- 客队基础λ = (客队加权场均进球×0.75 + 主队加权场均失球×0.25) × 动态客场折扣
- 无进球数据时用赔率反推：主队λ≈1/胜赔×2.5，客队λ≈1/负赔×2.5

**动态主客场系数（V2新增，替代固定1.15/0.90）：**
- 读取近30天该联赛所有比赛，计算主场胜率
- 主场加成 = 0.95 + (主场胜率 × 0.40)，范围约1.05-1.35
- 客场折扣 = 1.20 - (主场胜率 × 0.40)，范围约0.80-1.05
- 无法计算时回退默认值：主场1.15，客场0.90

#### 第二步：xG数据融合（V2新增）

当搜索到xG数据时，用xG替代实际进球计算更稳定的λ值：
- 若有xG数据：xG加权λ = (xG_for加权均值×0.75 + 对手xG_against加权均值×0.25) × 主客场系数
- 最终基础λ = 0.6 × 进球λ + 0.4 × xGλ（无xG时纯用进球λ）
- 标注："已融合xG数据，权重40%"

#### 第三步：H2H历史对战调整（强制执行，不可跳过）

**⚠️ 此步骤为必做步骤，H2H数据必须代入λ计算，不能只作为分析文字出现在报告中。**

**执行顺序：在计算基础λ之后、市场混合之前，必须先完成H2H搜索和调整因子计算。**

H2H调整分为两部分：A.总进球量调整（对称） + B.方向性调整（非对称，修正λ分配）

1. **WebSearch搜索H2H数据**（在计算λ之前完成）：
   - 搜索关键词：`"{主队} vs {客队} head to head results"` 或 `"{主队} {客队} 历史交锋 比分"`
   - 提取近6-10次交锋的具体比分（如2-1, 3-2, 1-1）
   - 统计：H2H总场次、主队胜场、平局场、客队胜场、总进球数、各场具体比分

2. **A部分：H2H总进球调整因子（对称调整）**：
   - H2H场均总进球 = 所有H2H比赛总进球 ÷ 比赛场次
   - H2H调整因子 = H2H场均总进球 ÷ 基础模型预期总进球(基础λ_主+基础λ_客)
   - 分级规则：
     - H2H场均≥4.0球：因子取max(因子,1.5)
     - H2H场均3.0-3.9：因子取max(因子,1.3)
     - H2H场均2.5-2.9：因子取max(因子,1.15)
     - H2H场均2.0-2.4：因子取max(因子,1.0)
     - H2H场均<2.0：因子取min(因子,0.9)
   - 应用：主队λ × 因子，客队λ × 因子（对称放大/缩小）

3. **B部分：H2H方向性调整（V2.2：总量守恒的λ再分配）**：

   **原理**：A 部分只按总进球做**对称缩放**，无法体现"某队被克制"。B 部分在**保持总进球量不变**的前提下，按 H2H 的胜负记录与进球分布，把 λ 从劣势方转移给优势方。
   总量守恒是关键 —— 它保证 B 部分不会破坏 A 部分已经校准好的进球量。

   **B-1 时间衰减加权**（权重与第一步基础λ一致，w_i = 0.85^i，i=0 为最近一场）：
   - 单场得分：主队胜=1，平=0.5，主队负=0
   - 加权胜率：`s_h2h = Σ(w_i × 得分_i) ÷ Σ(w_i)`
   - 加权进球占比：`p_h2h = Σ(w_i × 主队进球_i) ÷ Σ(w_i × 总进球_i)`

   **B-2 综合优势度**（进球占比为主、胜率为辅）：
   - `adv = 0.6 × p_h2h + 0.4 × s_h2h`
   - adv 取值 [0,1]，**0.5 表示势均力敌**，>0.5 主队占优，<0.5 客队占优

   **B-3 与基础模型占比混合**（α = 0.35，H2H 权重上限，避免小样本主导）：
   - `p_base = λ_主 ÷ (λ_主 + λ_客)`（用 A 部分调整后的 λ）
   - `p_mix = (1 - α) × p_base + α × adv`

   **B-4 总量守恒再分配（核心公式）**：
   - `λ_total = λ_主 + λ_客`（A 部分调整后的总量，保持不变）
   - `λ_主' = λ_total × p_mix`
   - `λ_客' = λ_total × (1 - p_mix)`
   - 校验：`λ_主' + λ_客' == λ_total`（必须在报告中体现总量未变）

   **B-5 限幅保护**（防止小样本 H2H 造成 λ 失真）：
   - 单侧调整幅度上限 **±25%**：若 `|λ_主' ÷ λ_主 - 1| > 0.25`，按 25% 截断
   - 截断后必须重新配平总量：把超出部分补给对手方

   **B-6 数据不足时**：
   - H2H 有效场次 < 3：跳过 B 部分，标注"H2H数据不足3场，跳过方向调整"，**但步骤不可省略**

   **V2.1 → V2.2 改进对照**：

   | 维度 | 旧版 V2.1 | 新版 V2.2 |
   |---|---|---|
   | 输入 | 仅胜率 | 加权胜率 + 加权进球占比（0.4/0.6） |
   | 映射 | 3档阶跃（≥70%/50-69%/接近） | **连续函数，无跳变** |
   | 进球占比 | 计算了但未使用 | 作为主权重真正参与 |
   | 总量 | λ主×1.12 / λ客×0.90，总量被改变 | **总量守恒，不破坏A部分** |
   | 场次权重 | 各场等权 | 时间衰减 0.85^i，近战权重更高 |
   | 保护 | 无 | ±25% 限幅并重新配平 |

   **示例**：诺丁汉森林 vs 热刺，H2H 近6场森林4胜2平0负
   - 衰减后：加权胜率 s=0.72，加权进球占比 p=0.63
   - 优势度 `adv = 0.6×0.63 + 0.4×0.72 = 0.666`
   - 基础占比 `p_base = 1.60 ÷ (1.60+1.20) = 0.571`
   - 混合占比 `p_mix = 0.65×0.571 + 0.35×0.666 = 0.604`
   - 总量守恒重分配：`λ_total = 2.80`，`λ_主' = 2.80×0.604 = 1.69`，`λ_客' = 2.80×0.396 = 1.11`
   - 校验：`1.69 + 1.11 = 2.80` ✅ 总量不变

4. **综合应用（A → B 顺序执行，不可颠倒）**：

   **A 阶段（对称，改变总量）**：
   - `λ_主_A = 基础主队λ × 总进球因子`
   - `λ_客_A = 基础客队λ × 总进球因子`

   **B 阶段（非对称，总量守恒）**：
   - `λ_total = λ_主_A + λ_客_A`（锁定，B 阶段后必须相等）
   - `λ_主' = λ_total × p_mix`，`λ_客' = λ_total × (1 - p_mix)`
   - 若触发 ±25% 限幅，截断后重新配平至 `λ_total`

   **⚠️ 校验要求**：报告中必须可验证 `λ_主' + λ_客' == λ_主_A + λ_客_A`。
   若不等，说明 B 阶段计算有误，必须重算。

   **必须在链路标注中显示**：H2H 场次、加权胜率、加权进球占比、优势度、混合占比、调整前后λ、总量校验值

5. **数据不足时的处理**：
   - H2H数据不足3场：标注"H2H数据不足3场，跳过调整"，但仍需在链路中显示此步骤
   - **绝不能直接省略此步骤**

6. **链路标注格式（必须包含H2H总进球+方向性调整，且顺序为 xG → H2H）**：
   ```
   基础λ(指数加权,主1.8客1.2) → xG融合(40%,主1.7客1.1) → H2H调整(近6场场均3.5球|总量因子1.3x→主2.21客1.43|方向再分配:加权胜率72%+进球占比63%→优势度0.666,混合占比0.604,总量守恒2.80→主1.69客1.11) → 市场混合(35%,主1.62客1.15) → 动态校准(×0.92) → 零封修正(P0×0.6) → 最终λ 主1.62 客1.15
   ```

   **⚠️ 顺序警告**：H2H 是第三步、xG 是第二步，链路中 **xG融合必须在 H2H调整之前**。
   写成 `基础λ → H2H调整 → xG融合` 属于严重错误，会导致 H2H 因子作用在未融合 xG 的 λ 上。

   **链路自检清单（输出HTML前逐条核对）**：
   - [ ] 含 `基础λ` / `xG`或`无xG` / `H2H调整` / `市场混合` / `动态校准` / `零封修正` / `最终λ` 共 7 段
   - [ ] H2H 段内同时出现**总量因子**与**方向再分配**两个数值
   - [ ] H2H 段内可验证 `调整前总量 == 调整后总量`
   - [ ] 每步括号中均有具体数值，无空白占位

#### 第四步：市场隐含λ混合（V2新增，融合赔率信息）

从赔率反推市场对进球数的预期，与模型λ做加权混合：
- 市场隐含主队λ = 1/胜赔 × 2.5（归一化后）
- 市场隐含客队λ = 1/负赔 × 2.5
- 混合公式：最终λ = 0.65 × 模型λ + 0.35 × 市场隐含λ
- 市场隐含λ作为"聪明钱"信号，修正模型偏差

#### 第五步：动态系数自校准（V2核心改进，基于历史预测命中率追踪）

**校准原理**：每天报告的"历史预测命中率追踪"部分会统计最近7天的预测准确率。根据偏差方向自动调整系数。

**校准流程（每次分析时执行）：**
1. 读取最近3-7天的报告，提取预测总进球 vs 实际总进球
2. 计算系统偏差比 = 平均(预测总进球 / 实际总进球)
   - 偏差比 > 1.10：模型系统性高估 → λ乘以0.92
   - 偏差比 < 0.90：模型系统性低估 → λ乘以1.08
   - 偏差比在0.90-1.10：无需校准
3. 计算方向命中率（胜平负方向预测准确率）
   - 方向命中率 < 45%：信心评级额外减1星
   - 方向命中率 > 60%：信心评级额外加1星
4. 计算比分命中率
   - 比分命中率 < 10%：标注"近期比分预测偏低，建议关注方向而非精确比分"
5. 按联赛分组校准（不同联赛偏差不同）：
   - 如英超预测偏高但西甲准确 → 仅调整英超的系数

**报告中标注校准信息：**
```
📊 动态校准：
- 近7场预测总进球均值: 3.2 | 实际均值: 2.8 → 系统高估14% → λ×0.92已应用
- 方向命中率: 52% (近7场命中4/7) → 信心评级不变
- 比分命中率: 14% (近7场命中1/7)
```

#### 第六步：零封修正（V2.1新增，解决0封比分偏多问题）

泊松分布 P(0;λ)=e^(-λ)，当λ较低时0球概率被高估。通过球队历史进球能力数据修正零封概率。

**修正逻辑：**

1. **计算球队零封频率**（搜索近10-15场战绩）：
   - 零封频率 = 未进球场次 ÷ 总场次
   - 如某队近15场有3场未进球 → 零封频率=20%

2. **计算进球连续性指标**：
   - 连续进球场次 = 近期最长连续进球场次数
   - 如某队近15场连续进球12场 → 进球连续性=80%

3. **零封修正因子计算**：
   - 零封频率 ≤ 15%（强进球能力）：P(0)×0.6（大幅降低零封概率，λ相应提升）
   - 零封频率 16-25%（中等进球能力）：P(0)×0.8
   - 零封频率 26-40%（进球能力一般）：P(0)×1.0（不调整）
   - 零封频率 > 40%（进攻乏力）：P(0)×1.2（适当提高零封概率）

4. **双方综合修正**：
   - 主队修正因子 = f(主队零封频率)
   - 客队修正因子 = f(客队零封频率)
   - 修正后P(主队0球) = 原P(主队0球) × 主队修正因子
   - 修正后P(客队0球) = 原P(客队0球) × 客队修正因子

5. **重新归一化**：修正后各比分概率需重新归一化，确保总和=100%

6. **标注信息**：
   ```
   零封修正：主队近15场零封2次(13%)→P(0)×0.6 | 客队近15场零封5次(33%)→P(0)×1.0
   修正后0-0概率: 4.2%→2.5% | 1-0概率: 12%→9.8% | 2-1概率: 11%→14.5%
   ```

**参考数据来源（WebSearch）**：
- `"{球队} goals scored last 10 games"` 或 `"{球队} 近10场进球"`
- `"{球队} failed to score"` 搜索零封记录
- 联赛积分榜中的进球数/场均进球列

#### 第七步：泊松计算与输出
- P(k;λ)=e^(-λ)×λ^k/k!，遍历k1=0..6,k2=0..6
- 取概率最高的2-3个比分，标注概率百分比
- 标注完整调整链路信息（7步必须全部出现，缺步必须补算）：
  ```
  基础λ(指数加权,主1.8客1.2) → xG融合(40%,主1.7客1.1) → H2H调整(近6场场均3.5球,总进球因子1.3x+方向因子:主队胜率67%→主×1.12/客×0.90,主2.63客1.40) → 市场混合(35%,主2.0客1.3) → 动态校准(×0.92,主1.84客1.20) → 零封修正(P0×0.6,主1.84客1.20) → 最终λ 主1.84 客1.20
  ```

### 2.4 冷门信号检测
发现异常时调低信心1-2星并标注⚠️：
