### 项目概况
- **JinBet** — 竞彩足球投注记录与分析工具，部署在 GitHub Pages (https://jinbigbig.github.io/jinbet/)
- 单文件 HTML 应用 (index.html, ~6945 行)，数据存储在浏览器 localStorage
- Python 脚本从网易体育抓取赔率，GitHub Actions 每日自动更新
- 双分支架构：master(源码) + gh-pages(静态部署)

### 核心组件
1. **index.html** — 主应用，支持胜平负/让球/比分/总进球/半全场 5 种玩法，含盈亏统计
2. **prediction.html / predictions/** — AI 赛果预测报告，按日期归档 (7/21~7/29)
3. **ai_prediction_sandbox.html** — AI 预测沙盒原型
4. **odds_data.json** — 当前赔率数据 (26 场比赛, 更新于 2026-07-29 06:58)
5. **Python 脚本**:
   - `fetch_odds.py` — 抓取网易赔率 → odds_data.json
   - `update_odds_net.py` — 抓取 + 注入 index.html + 更新 JSON (CI 调用)
   - `update_163_odds.py` — 完整版抓取 + 注入
   - `push_bets.py` — 推送投注记录到 gh-pages
   - `clear_bets.py` — 清空线上投注记录
   - `odds_proxy.py` — 本地 CORS 代理 (127.0.0.1:51888)
6. **.github/workflows/daily-update.yml** — CI, cron UTC 3:15 (北京 11:15)
7. **tools/** — 8 个一次性调试脚本

### 技术栈
- 前端：纯 HTML/CSS/JS (单文件, 无框架)
- 后端：Python 标准库 (urllib/json/re/html)
