## 球小策球员评分：接入可行性 + Matlas 详情页落地

### 数据源结论（探针验证，非推测）
- 球小策球员数据中心 `https://www.qiuxiaoce.com/player-rankings/` 是**服务端渲染**，内嵌
  `ABV2_DC = {apiUrl, ajaxUrl, nonce}`；联赛切换走 admin-ajax 的 `abv2_dc_rankings`。
  参数 `league_id / metric / limit(上限 100) / offset`，参数名是 `league_id` 不是 `league`。
  **nonce 每次现取**（写死几小时后 403 返回 -1）。
- 对外只公开 6 项：OTI 进攻威胁 / DII 防守参与 / GIM 比赛影响力 / form_rating 状态(0-10 EWMA) /
  consistency_score / fatigue_risk+fatigue_load。宣传的「硬仗属性」「缺阵影响」**接口里没有**。
- 51 个联赛，除澳超（每队 1-5 人）、杯赛（0 人）外，每队 10-20 人。约 5000 人。
- **队名中文完全一致**（威廉二世/兹沃勒/埃弗顿…），零映射成本；仅少数巴西队需别名
  （帕梅拉斯→帕尔梅拉斯、米竞技→米内罗竞技、布拉干RB→布拉干蒂诺RB、瓦斯科→瓦斯科达伽马等 11 条）。
- **球员名不可跨源匹配**：源站中文是自译（「加鲁乔」），我们的伤停是港译（「霍夫斯洛特」）；
  源站部分球员 display_name 直接等于英文名（"R. Youlley"）。实测伤停名命中 **0/107** → 放弃交叉。
- 官方 API（`/wp-json/abv2-creator/v1`，需 X-API-Key）match-pack 50 点=0.5 元/场，未用。
- **上游是 FotMob**（文档字段名 `fotmob_rating`/`optaId`/`sca90`/`xg_chain` 露馅）。FotMob 可直连：
  `api/data/matches?date=YYYYMMDD` 200/305KB；`api/data/matchDetails?matchId=` 200/331KB
  （playerStats 5 组 49 项/人 + shotmap + momentum + attackingZones + heatmap）；
  `api/data/teams?id=` 480KB。**赛前 playerStats 为空、只有 lineup**，评分只在赛后。
