- **结论口径**：此种情形**不要再试 rebase**，直接走记忆里那条 `cp 报告 → git reset --hard <ls-remote 真实SHA> → 写回报告 → 单提交 → push`；本次即以此成功（`6682b26 → e1bd232 → d9ce365`）。
